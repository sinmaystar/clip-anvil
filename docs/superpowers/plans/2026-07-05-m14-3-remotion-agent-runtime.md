# M14.3 Remotion Agent Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the fixed Remotion Agent Runtime and sandbox job service path that renders a validated `agent_remotion_code_v1` attempt workspace into a final MP4 without adding Composer tools yet.

**Architecture:** The generated renderer remains in `/workspace/agent-remotion/<renderer_artifact_id>/<attempt_no>/`. `render.mjs` creates a per-attempt runtime directory under that workdir, writes a controlled `harness.tsx`, links runtime `node_modules`, validates props/output paths, invokes Remotion CLI with composition id `AgentGeneratedVideo`, then leaves the MP4 at `/workspace/output/...`. Go adds `RenderAgentRemotionCode` to `JobService`, records a sandbox job, runs the fixed runtime, inspects MIME/size, probes video metadata, and returns output metadata that later M14.4 tools can persist to the renderer attempt.

**Tech Stack:** Go 1.26, existing sandbox `JobService`, OpenSandbox `Client`, Remotion 4.0.484, React 19, TypeScript 6, Node ESM scripts, ffprobe via sandbox ffmpeg package.

## Runtime Contract

`render.mjs` must accept:

```text
node /opt/clipanvil/remotion-agent-runtime/src/render.mjs \
  --workdir /workspace/agent-remotion/<renderer_artifact_id>/<attempt_no> \
  --out /workspace/output/final-<timeline_plan_id>.mp4 \
  --browser-executable /usr/bin/chromium-headless-shell \
  --public-dir /workspace
```

Generated attempt files:

```text
/workspace/agent-remotion/<renderer_artifact_id>/<attempt_no>/
  GeneratedComposition.tsx
  props.json
  optional files such as styles.ts, copy.ts, components/Card.tsx
```

Runtime-created files:

```text
/workspace/agent-remotion/<renderer_artifact_id>/<attempt_no>/.clipanvil-runtime/
  harness.tsx
  node_modules -> /opt/clipanvil/remotion-agent-runtime/node_modules
  generated/GeneratedComposition.tsx
  generated/...
  runtime/safe.ts
```

The harness composition id is fixed:

```text
AgentGeneratedVideo
```

Props output contract:

```json
{
  "output": {
    "width": 1080,
    "height": 1920,
    "fps": 30,
    "duration_sec": 6
  }
}
```

Use a sandbox command:

```bash
ffprobe -v error -print_format json -show_streams -show_format '<output>'
```

Parse JSON:

- `format.duration` -> `DurationSec`.
- first `codec_type=video` stream -> `VideoStream=true`, `Width`, `Height`.

If ffprobe fails, return an error so the job fails.
