# M1 Agent Creative State Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build M1 Agent creative state so Producer can create and read CreativeBrief, ProjectMemory, KeyElement, KeyElementState, Scene, Shot, ShotKeyElement, and ShotDependency facts through Eino-native typed tools.

**Architecture:** Business database tables are the source of truth; Producer writes domain facts through typed Eino tools; PSS/read context and canvas projection read those facts. M1 does not generate images/videos and does not dispatch Craftsman/Reviewer. Existing legacy tools may remain in the repo, but Producer M1 registration should use the new native typed tools.

**Tech Stack:** Go 1.26, Hertz, pgx v5, sqlc, PostgreSQL 16, CloudWeGo Eino `compose.Graph` / `compose.ToolsNode`, `components/tool/utils.GoStruct2ParamsOneOf`, React 19 + TypeScript 6 + `@xyflow/react`.

---

## Scope

M1 includes:

- New database tables and `shot` extensions from `docs/superpowers/specs/2026-06-25-m1-agent-creative-state-design.md`.
- New sqlc queries and generated store types.
- A focused `creative_state` domain service.
- Native Eino typed Producer tools for the five M1 tools.
- Producer system prompt replacement from `docs/superpowers/specs/2026-06-25-producer-agent-contract-design.md`.
- Full Context Packet / PSS support for M1 domain facts.
- Read-only canvas projection for M1 domain facts.
- A deterministic/e2e path for the Yuexing luggage airport ad example.

M1 excludes:

- `render_plan`.
- PromptCompiler.
- Seedream / Seedance execution.
- Craftsman and Reviewer execution.
- Editable domain nodes on the canvas.

func (r NaturalResult) String() string {
	status := "工具执行成功"
	if strings.TrimSpace(r.Status) != "" && r.Status != "success" {
		status = "工具执行完成"
	}
	var b strings.Builder
	b.WriteString(status)
	if title := strings.TrimSpace(r.Title); title != "" {
		b.WriteString("：")
		b.WriteString(title)
	}
	b.WriteString("。\n")
	if len(r.Items) > 0 {
		b.WriteString("\n关键结果：\n")
		for _, item := range r.Items {
			label := strings.TrimSpace(item.Label)
			value := strings.TrimSpace(item.Value)
			if label == "" && value == "" {
				continue
			}
			if label == "" {
				fmt.Fprintf(&b, "- %s\n", value)
				continue
			}
			fmt.Fprintf(&b, "- %s: %s\n", label, value)
		}
	}
	if next := strings.TrimSpace(r.Next); next != "" {
		b.WriteString("\n下一步建议：")
		b.WriteString(next)
		if !strings.HasSuffix(next, "。") {
			b.WriteString("。")
		}
		b.WriteString("\n")
	}
	return strings.TrimSpace(b.String())
}

package tools

import (
	"context"
	"sort"

	einotool "github.com/cloudwego/eino/components/tool"
	"github.com/cloudwego/eino/schema"
)

type NativeTool interface {
	einotool.InvokableTool
	NativeDefinition(ctx context.Context) (NativeDefinition, error)
}

type NativeDefinition struct {
	Name string
	Safety SafetySpec
	Visibility VisibilitySpec
}

type NativeRegistry struct {
	tools map[string]NativeTool
}

func NewNativeRegistry(tools ...NativeTool) (*NativeRegistry, error) {
	registry := &NativeRegistry{tools: map[string]NativeTool{}}
	for _, t := range tools {
		if t == nil {
			continue
		}
		info, err := t.Info(context.Background())
		if err != nil {
			return nil, err
		}
		if _, exists := registry.tools[info.Name]; exists {
			return nil, ErrDuplicateTool
		}
		registry.tools[info.Name] = t
	}
	return registry, nil
}

func (r *NativeRegistry) Tools() []einotool.BaseTool {
	if r == nil {
		return nil
	}
	names := make([]string, 0, len(r.tools))
	for name := range r.tools {
		names = append(names, name)
	}
	sort.Strings(names)
	out := make([]einotool.BaseTool, 0, len(names))
	for _, name := range names {
		out = append(out, r.tools[name])
	}
	return out
}

func (r *NativeRegistry) ToolInfo(ctx context.Context) ([]*schema.ToolInfo, error) {
	tools := r.Tools()
	out := make([]*schema.ToolInfo, 0, len(tools))
	for _, t := range tools {
		info, err := t.Info(ctx)
		if err != nil {
			return nil, err
		}
		out = append(out, info)
	}
	return out, nil
}
