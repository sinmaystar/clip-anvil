# M9.5 Media Strategy and Real E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete media-aware context compaction and prove it with a real browser marketing-video generation flow whose DB records, tool traces, sandbox detail files, and Agent chat list remain auditable.

**Architecture:** Keep M9.1-M9.4 as the shared compaction foundation. M9.5 enriches media cards, ensures Composer probe/stage/ffmpeg outputs are recoverably compacted, records compaction diagnostics as agent events/metadata, then runs a clean real E2E flow through the browser and database. The Agent chat list remains source-of-truth `agent_message`; compressed prompt projections and detail files stay sidecar-only.

**Tech Stack:** Go 1.26, Eino `schema.Message`, `contextcompact` media cards, Composer sandbox/ffmpeg tools, PostgreSQL/sqlc, browser smoke via local dev app, `GOCACHE=/private/tmp/clipanvil-go-build make server-test`, optional `pnpm --filter @clip-anvil/web... build/lint` only if frontend changes.

## Hard Boundaries

In scope:

- Complete image / video / audio `MediaCard` fields from trusted DB/tool/probe sources.
- Add media-card builders where contexts already have media facts.
- Ensure Composer stage/probe/ffmpeg large outputs are candidates for micro compact and recoverable through `detail_file`.
- Add compaction diagnostics event or metadata that records token_before, token_after, mode, compact refs, and detail files.
- Run a real browser E2E marketing video flow after implementation.
- Inspect DB rows for `agent_context_compaction`, `agent_message_compaction`, `agent_message`, `artifact_version`, `producer_pending_signal`, and timeline/final output state.
- Inspect sandbox `/workspace/.clipanvil/context/` detail files and recover at least one long result with `read_file`.

Out of scope:

- No vector database.
- No UI for editing summaries.
- No new `list_files` native tool; use exec shell for listing.
- No change to Producer pending signal claim / drain timing.
- No replacement of Agent chat-list messages with compact placeholders.
- No fabricated media summary. Missing visual/audio summary must remain `未生成视觉摘要` or `未生成音频摘要`.
